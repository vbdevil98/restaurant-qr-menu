Put your dish photos in this folder.

Name them to match the "image" path in data/restaurants.js, for example:
  butter-chicken.jpg   ->   image: "/images/dishes/butter-chicken.jpg"

Tips:
- Square-ish photos look best (e.g. 1000 x 1000). They're shown cropped.
- Use .jpg or .webp and keep each file under ~300 KB so the menu loads fast.
- No photo yet? The menu automatically shows a colored tile with the dish
  emoji, so it still looks finished. Add the photo later and it appears.
